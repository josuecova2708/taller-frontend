# Taller Frontend — Next.js

Web dashboard for the OBD-II vehicle diagnostic platform.

## Prerequisites

- Node.js 22 LTS
- Backend running on port 3000

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

The app will be available at `http://localhost:3000` (or `http://localhost:3001` if port 3000 is in use by the backend).

## Pages

- `/login` — Login page
- `/dashboard` — Fleet overview
- `/dashboard/vehicles` — Vehicle management
- `/dashboard/scans` — Scan history
- `/dashboard/work-orders` — Work order management
